# AdmitCrew optional channels — demo only

Open channel-options.html in your browser to show the WhatsApp and Facebook options. This standalone page displays demo previews only. It does not connect an account, send a message, or change the main website.

Both channels are optional. The working demo continues to use the local student chat. Any real outgoing message must wait for staff approval.

channels.env.example documents the settings supported by the existing backend adapter. It contains no keys. Do not replace the existing .env, and do not enable external delivery for this practice project. The existing meta_channels.py remains the backend implementation; this package does not replace it.

For the presentation: “WhatsApp and Facebook are optional integration channels. This project demonstrates staff-approved replies in the local test chat. Live Meta sending is not enabled.”
